IS 224 Web Development Lab – Week 2 Project Overview

This project is part of the Week 2 lab activity for the IS 224 Web Development course. The task involved building a simple multi-page website to demonstrate foundational HTML concepts including lists, tables, and forms.

Objectives

The main objectives of this project were:

To create a structured 3-page website To demonstrate the use of: Ordered and unordered lists Tables with advanced features (rowspan, colspan) Forms with validation To practice linking multiple web pages using navigation What Was Done

The following pages were developed:

    Home Page (index.html) Added a main heading: "Welcome to My Student Portal" Created: An ordered list for daily routine An unordered list for hobbies Included navigation links to other pages
    Timetable Page (timetable.html) Built a student timetable using a table Implemented:
